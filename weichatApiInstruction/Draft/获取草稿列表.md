## 获取草稿列表

### 接口请求说明
**HTTP 请求方式**：POST（请使用https协议）  
**请求地址**：
```
https://api.weixin.qq.com/cgi-bin/draft/batchget?access_token=ACCESS_TOKEN
```

### 调用示例
```json
{
    "offset": OFFSET,
    "count": COUNT,
    "no_content": NO_CONTENT
}
```

### 请求参数说明
| 参数       | 是否必须 | 说明                                 |
| ---------- | -------- | ------------------------------------ |
| offset     | 是       | 起始偏移量（0表示第一个）            |
| count      | 是       | 返回数量（1-20）                     |
| no_content | 否       | 是否返回content字段（0返回/1不返回） |

### 接口返回说明
```json
{
    "total_count": TOTAL_COUNT,
    "item_count": ITEM_COUNT,
    "item": [
        {
            "media_id": "MEDIA_ID",
            "content": {
                "news_item": [
                    {
                        "article_type": "news",
                        "title": "TITLE",
                        "author": "AUTHOR",
                        "digest": "DIGEST",
                        "content": "CONTENT",
                        "content_source_url": "CONTENT_SOURCE_URL",
                        "thumb_media_id": "THUMB_MEDIA_ID",
                        "show_cover_pic": 0,
                        "need_open_comment": 0,
                        "only_fans_can_comment": 0,
                        "url": "URL"
                    }
                ]
            },
            "update_time": UPDATE_TIME
        }
    ]
}
```

### 返回参数说明
| 参数                  | 描述                   |
| --------------------- | ---------------------- |
| total_count           | 草稿总数               |
| item_count            | 本次获取数量           |
| media_id              | 图文消息ID             |
| title                 | 标题                   |
| author                | 作者                   |
| digest                | 摘要（单图文有效）     |
| content               | 正文内容（支持HTML）   |
| content_source_url    | 原文地址               |
| thumb_media_id        | 封面永久MediaID        |
| show_cover_pic        | 是否显示封面（已废弃） |
| need_open_comment     | 是否打开评论           |
| only_fans_can_comment | 是否仅粉丝可评论       |
| url                   | 临时链接               |
| update_time           | 最后更新时间           |
| image_info            | 图片信息（最多20张）   |
| image_media_id        | 图片永久MediaID        |
| product_info          | 商品信息               |
| footer_product_info   | 文末商品信息           |
| product_key           | 商品key                |
