## 修改草稿

开发者可通过本接口对草稿进行修改。

### 接口请求说明
**HTTP 请求方式**：POST（请使用https协议）  
**请求地址**：
```
https://api.weixin.qq.com/cgi-bin/draft/update?access_token=ACCESS_TOKEN
```

### 调用示例
#### 图文消息
```json
{
    "media_id": "MEDIA_ID",
    "index": INDEX,
    "articles": {
        "article_type": "news",
        "title": "TITLE",
        "author": "AUTHOR",
        "digest": "DIGEST",
        "content": "CONTENT",
        "content_source_url": "CONTENT_SOURCE_URL",
        "thumb_media_id": "THUMB_MEDIA_ID",
        "need_open_comment": 0,
        "only_fans_can_comment": 0,
        "pic_crop_235_1": "X1_Y1_X2_Y2",
        "pic_crop_1_1": "X1_Y1_X2_Y2"
    }
}
```

#### 图片消息
```json
{
    "media_id": "MEDIA_ID",
    "index": INDEX,
    "articles": {
        "article_type": "newspic",
        "title": "TITLE",
        "content": "CONTENT",
        "need_open_comment": 0,
        "only_fans_can_comment": 0,
        "image_info": {
            "image_list": [
                {
                    "image_media_id": "IMAGE_MEDIA_ID"
                }
            ]
        },
        "cover_info": {
            "crop_percent_list": [
                {
                    "ratio": "1_1",
                    "x1": "0.166454",
                    "y1": "0",
                    "x2": "0.833545",
                    "y2": "1"
                }
            ]
        },
        "product_info": {
            "footer_product_info": {
                "product_key": "PRODUCT_KEY"
            }
        }
    }
}
```

### 请求参数说明
| 参数                  | 是否必须 | 说明                                      |
| --------------------- | -------- | ----------------------------------------- |
| media_id              | 是       | 要修改的图文消息的id                      |
| article_type          | 否       | 文章类型（news/newspic）默认news          |
| index                 | 是       | 要更新的文章位置（多图文时有效），首篇为0 |
| title                 | 是       | 标题                                      |
| author                | 否       | 作者                                      |
| digest                | 否       | 图文摘要（单图文有效）默认取前54字        |
| content               | 是       | 正文内容（支持HTML，<2万字符，<1M）       |
| content_source_url    | 否       | 原文地址（"阅读原文"链接）                |
| thumb_media_id        | 是       | 封面图片永久MediaID                       |
| need_open_comment     | 否       | 是否打开评论（0关闭/1打开）               |
| only_fans_can_comment | 否       | 是否仅粉丝可评论（0所有人/1粉丝）         |
| pic_crop_235_1        | 否       | 2.35:1封面裁剪坐标（X1_Y1_X2_Y2格式）     |
| pic_crop_1_1          | 否       | 1:1封面裁剪坐标                           |
| image_info            | 是       | 图片消息相关信息（最多20张）              |
| image_media_id        | 是       | 图片永久MediaID                           |
| crop_percent_list     | 否       | 封面裁剪比例（支持1_1/16_9/2.35_1）       |
| product_info          | 否       | 商品相关信息                              |
| footer_product_info   | 否       | 文末商品信息                              |
| product_key           | 否       | 商品key                                   |

### 接口返回说明
```json
{
    "errcode": ERRCODE,
    "errmsg": "ERRMSG"
}
```

### 错误码说明
| 错误码 | 错误信息                   | 解决方案           |
| ------ | -------------------------- | ------------------ |
| 40114  | invalid index value        |                    |
| 41039  | invalid content_source_url |                    |
| 45166  | invalid content            |                    |
| 88000  | without comment privilege  |                    |
| 53404  | 账号已被限制带货能力       | 请删除商品后重试   |
| 53405  | 插入商品信息有误           | 检查参数和商品状态 |
| 53406  | 请先开通带货能力           |                    |
