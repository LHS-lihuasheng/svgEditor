## 删除草稿

新增草稿后，开发者可以根据本接口来删除不再需要的草稿，节省空间。此操作无法撤销，请谨慎操作。

### 接口请求说明
**HTTP 请求方式**：POST（请使用https协议）  
**请求地址**：
```
https://api.weixin.qq.com/cgi-bin/draft/delete?access_token=ACCESS_TOKEN
```

### 调用示例
```json
{
    "media_id": "MEDIA_ID"
}
```

### 请求参数说明
| 参数 | 是否必须 | 说明 |
|------|----------|------|
| access_token | 是 | 调用接口凭证 |
| media_id | 是 | 要删除的草稿的media_id |

### 接口返回说明
```json
{
    "errcode": ERRCODE,
    "errmsg": "ERRMSG"
}
```

### 返回参数说明
| 参数 | 说明 |
|------|------|
| errcode | 错误码 |
| errmsg | 错误信息 |

> 注意：多次删除同一篇草稿也返回 0

### 错误码说明
| 错误码 | 错误信息 | 解决方案 |
|-------|---------|----------|
| 公共错误码 | 点击查看 |  |
