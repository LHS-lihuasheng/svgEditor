# 新增永久素材

对于常用的素材，开发者可通过本接口上传到微信服务器，永久使用。新增的永久素材也可以在公众平台官网素材管理模块中查询管理。

## 注意事项

1. **最近更新**：永久图片素材新增后，将带有URL返回给开发者，开发者可以在腾讯系域名内使用（腾讯系域名外使用，图片将被屏蔽）
2. **素材库容量限制**：
   - 图文消息素材、图片素材上限为100000
   - 其他类型素材上限为1000
3. **素材格式要求**：
   - 图片（image）: 10M，支持bmp/png/jpeg/jpg/gif格式
   - 语音（voice）：2M，播放长度不超过60s，mp3/wma/wav/amr格式  
   - 视频（video）：10MB，支持MP4格式
   - 缩略图（thumb）：64KB，支持JPG格式
4. 图文消息内容中的外部图片链接将被过滤，需通过"上传图文消息内的图片获取URL"接口获取图片URL
5. "上传图文消息内的图片获取URL"接口上传的图片：
   - 不占用素材库图片数量限制
   - 仅支持jpg/png格式
   - 大小必须<1MB
6. 图文消息支持在正文插入自己账号和其他公众号已群发文章链接

## 上传图文消息内的图片获取URL

本接口所上传的图片不占用公众号素材库图片数量限制。

### 接口请求说明
**HTTP 请求方式**：POST（HTTPS协议）  
**请求地址**：
```
https://api.weixin.qq.com/cgi-bin/media/uploadimg?access_token=ACCESS_TOKEN
```

**调用示例**：
```bash
curl -F media=@test.jpg "https://api.weixin.qq.com/cgi-bin/media/uploadimg?access_token=ACCESS_TOKEN"
```

### 请求参数说明
| 参数          | 是否必须 | 说明                                      |
|---------------|----------|-----------------------------------------|
| access_token  | 是       | 调用接口凭证                              |
| media         | 是       | form-data中媒体文件标识，包含filename、filelength、content-type等信息 |

### 返回说明
正常返回结果：
```json
{
    "url": "http://mmbiz.qpic.cn/mmbiz/gLO17UPS6FS2xsypf378iaNhWacZ1G1UplZYWEYfwvuU6Ont96b1roYsCNFwaRrSaKTPCUdBK9DgEHicsKwWCBRQ/0"
}
```
> 返回的url可用于图文消息中

## 新增其他类型永久素材

### 接口请求说明
**HTTP 请求方式**：POST（HTTPS协议）  
**请求地址**：
```
https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=ACCESS_TOKEN&type=TYPE
```

**调用示例**：
```bash
curl "https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=ACCESS_TOKEN&type=TYPE" -F media=@media.file
```

### 请求参数说明
| 参数          | 是否必须 | 说明                                      |
|---------------|----------|-----------------------------------------|
| access_token  | 是       | 调用接口凭证                              |
| type          | 是       | 媒体文件类型（image/voice/video/thumb）   |
| media         | 是       | form-data中媒体文件标识                   |

### 视频素材特殊说明
上传视频时需要额外表单字段：
```json
{
    "title": "VIDEO_TITLE",
    "introduction": "INTRODUCTION"
}
```

**视频调用示例**：
```bash
curl "https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=ACCESS_TOKEN&type=video" -F media=@media.file -F description='{"title":"VIDEO_TITLE", "introduction":"INTRODUCTION"}'
```

**视频参数说明**：
| 参数          | 是否必须 | 说明                 |
|---------------|----------|----------------------|
| title         | 是       | 视频标题（≤30字）     |

### 返回说明
```json
{
  "media_id": "MEDIA_ID",
  "url": "URL"
}
```

**返回参数说明**：
| 参数       | 描述                                |
|------------|-----------------------------------|
| media_id   | 新增的永久素材media_id              |
| url        | 图片素材URL（仅图片类型返回该字段）  |

**错误示例**：
```json
{"errcode":40007,"errmsg":"invalid media_id"}
```
